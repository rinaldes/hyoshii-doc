# Getting Started with Hyoshii App

Welcome to Hyoshii App, your comprehensive solution for managing strawberry farm cultivation. This guide will help you set up and start using the application effectively.

## Installation

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Internet connection
- Valid Hyoshii App account

### Steps to Get Started
1. **Create an Account**
   - Visit [Hyoshii App](https://app.hyoshii.com/signup)
   - Fill in your details and create your account
   - Verify your email address

2. **Log In**
   - Go to [Hyoshii App Login](https://app.hyoshii.com/login)
   - Enter your credentials
   - Complete two-factor authentication if enabled

3. **Initial Setup**
   - Complete your profile information
   - Set up your farm details
   - Configure your preferences

## First Steps

### Adding Your First Farm Location
1. Navigate to **Locations** in the main menu
2. Click **Add New Location**
3. Enter location details (name, address, GPS coordinates)
4. Save the location

### Setting Up Production Areas
1. Go to **Production** > **Areas**
2. Click **Add New Area**
3. Select the farm location
4. Define the area size and characteristics
5. Save the area

### Creating Your First Production Report
1. Navigate to **Production** > **Reports**
2. Click **New Report**
3. Select the production area
4. Enter the production data
5. Submit the report
