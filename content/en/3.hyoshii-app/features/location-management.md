# Location Management

Effectively manage all your strawberry farm locations, plots, and growing areas with Hyoshii App's comprehensive location management system.

## Overview

Location management in Hyoshii App allows you to:
- Organize multiple farm locations in one place
- Manage plots and growing areas
- Track location-specific data and metrics
- Assign teams and resources to specific locations

## Setting Up Locations

### Adding a New Farm Location
1. Navigate to **Locations** in the main menu
2. Click **+ Add Location**
3. Fill in the location details:
   - Location name
   - Address
   - GPS coordinates (optional)
   - Contact information
   - Operating hours
4. Click **Save**

### Adding Plots to a Location
1. Select a location from the Locations list
2. Click **Add Plot**
3. Enter plot details:
   - Plot name/number
   - Size (in hectares or acres)
   - Soil type
   - Planting date
   - Strawberry variety
4. Upload any relevant documents or images
5. Click **Save**

## Managing Growing Areas

### Creating Growing Areas
1. From the location view, select **Growing Areas**
2. Click **Add Growing Area**
3. Define the area:
   - Area name
   - Size and dimensions
   - Growing method (e.g., soil, hydroponic, vertical)
   - Irrigation system details
   - Environmental controls (if applicable)
4. Map the area boundaries using the drawing tool
5. Click **Save**

### Tracking Area Conditions
1. Select a growing area
2. Navigate to the **Conditions** tab
3. Record current conditions:
   - Temperature
   - Humidity
   - Soil moisture
   - Light levels
   - pH levels
4. Set up automated sensor data integration (if available)
